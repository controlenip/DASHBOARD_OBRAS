NIP IA - instalação no Streamlit

1. Substitua no repositório: app_nip.py, nip_dashboard_template.html e requirements.txt.
2. Adicione o arquivo novo nip_ai.py na mesma pasta.
3. Mantenha os arquivos de dados e nip_analytics.py já existentes.
4. Streamlit Cloud > App settings > Secrets:
   OPENAI_API_KEY = "sua-chave-de-API"
   OPENAI_MODEL = "gpt-4.1-mini"
5. Reinicie o aplicativo e use o botão NIP IA na parte superior.
6. Faça uma consulta. Para executar ação de mapa, clique Aplicar no mapa.

IMPORTANTE:
- O agente não edita planilhas nem publica dados no GitHub.
- A proximidade usa coordenadas de residência em linha reta.
- Ações disponíveis: localizar nota, filtrar mapa, limpar mapa.
- Consultas: status de nota, totais por agrupamento, pendências por data de despacho, proximidade residencial.
- Dados operacionais são enviados parcialmente à API OpenAI nas consultas. Antes de habilitar para terceiros, avalie a política de dados, acesso e custos.
- Interface: popover nativo do Streamlit sobre a página (não um chat embutido no iframe).
- Testes feitos: sintaxe Python e JS; testes locais de operações sem API. Não foi realizado teste real com API ou publicação Streamlit.
